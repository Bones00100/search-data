# Сбор и анализ цен на мясные товары магазина Лента


Проект нужен для автоматизированного сбора цен на мясные товары в розничном магазине «Лента» в городе Москве

Данные получаются через API магазина и сохраняются в форматах CSV и JSON

Проект позволяет:

-получать список товаров категории «Мясо»;
-получать актуальные цены;
-получать обычные цены товаров;
-определять вес товара;
-рассчитывать цену за 1 кг;
-распределять товары по группам;
-сохранять ссылки на товары;
-и другое


Магазин:

- ID: 0291
- Адрес: ул. Бибиревская 10 к.2
- Тип: гипермаркет

## Категория

Мясо

## Источник данных

Для получения данных используется API Ленты:

https://integration.api.lenta.com/catalog/v1/items

При запросах используется магазин с ID 0291 и категория 136 | Между запросами устанавливается пауза 3 секунды

## Файлы проекта

### main.py

Получает товары через API, обрабатывает их и сохраняет результаты

### scraper.py

Отвечает за:

запросы к API; получение товаров; получение цены; получение веса; расчёт цены за килограмм; формирование ссылки на товар

### storage.py

Сохраняет в:

CSV; JSON

### generate_yaml.py

Формирует файл `config/products.yaml` с ссылками на товары

### basket.py

Формирует стоимость на сумму около 1/4 МРОТ Москвы

## История цен

При каждом запуске новые значения добавляются в CSV и JSON

Таким образом можно получить историю:

дата -> товар -> цена -> цена за кг.

Для анализа инфляции скрипт можно запускать один раз в неделю
