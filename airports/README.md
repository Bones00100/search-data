**Парсинг данных по аэропортам всего мира**.

В данном проекте находится скрипт для сбора и обработки данных (парсинга) по аэропортам со всего мира. Также уже есть собранные данные, готовые, где видно всю информацию о них. Отлично подходит для работы со сбором данных и обработки их для начального этапа в этой стороне IT.

Данные частично взяты с нескольких ресурсов:

1. [skybrary](https://skybrary.aero/)
2. [kaggle](https://www.kaggle.com/datasets/sanjeetsinghnaik/world-airport-dataset?select=airports.csv)
3. Были ещё, но их много просмотрел, потерялись.


Файлы .csv и .json не со всеми данными, потому что слишком большие получились.
